# Branching Strategy
- main: stable production branch
- feature/firebase-auth: Firebase Authentication implementation
- feature/firestore-db: Firestore real-time database integration
- feature/fcm-notifications: Push notification implementation
- feature/jetpack-compose: Compose UI screens
- feature/remote-config: Firebase Remote Config feature
- feature/crashlytics-analytics: Firebase Crashlytics and Analytics

Each branch is merged to main via a Pull Request with at least one peer review comment.
