ARCHITECTURE OVERVIEW:
- Pattern: MVVM (Model-View-ViewModel)
- UI Layer: Fragments (existing) + Jetpack Compose (new screens)
- Data Layer: Room DB (local, from A03) + Firebase Firestore (cloud, new)
- Auth Layer: Firebase Authentication (Email + Google)
- Notification Layer: Firebase Cloud Messaging
- Observability: Firebase Crashlytics + Analytics
- Remote Control: Firebase Remote Config
- Async: Kotlin Coroutines + ViewModelScope throughout

SELF-RESEARCHED FEATURES JUSTIFICATION:
Feature A (Remote Config): Enables server-side control of app behavior without releasing a new APK. Official docs: https://firebase.google.com/docs/remote-config
Feature B (Crashlytics + Analytics): Industry standard for monitoring app stability and user behavior. Official docs: https://firebase.google.com/docs/crashlytics
